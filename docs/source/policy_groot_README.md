## Original-vs-LeRobot parity test

`tests/policies/groot/test_groot_vs_original.py` compares LeRobot's GR00T N1.7
implementation with NVIDIA's original `gr00t` package for every embodiment in the
generated artifacts:

1. **Model parity:** identical collated inputs and flow-matching seed must yield
   matching raw `get_action(...)["action_pred"]` values within the configured
   tolerance, with identical action-horizon and action-dimension shapes.
2. **Preprocessor parity:** identical raw camera frames, states, and instructions
   must yield matching `input_ids`, `attention_mask`, `pixel_values`, `image_grid_thw`,
   `state`, and `embodiment_id`, using the real tokenizer, image packing, and
   checkpoint-driven normalization.

### Why two environments

The original package uses Python 3.10 and `transformers==4.57.3`; LeRobot requires
`transformers>=5.x`. Importing the original config under 5.x fails with
`non-default argument follows default argument`, so use separate environments:

- **Producer:** run `tests/policies/groot/utils/dump_original_n1_7.py` in the original
  GR00T environment. It builds dummy observations from checkpoint metadata and saves
  one `.npz` per embodiment containing raw observations (`raw::`), collated inputs
  (`in::`), the seed, and `action_pred`.
- **Consumer:** run the pytest in the LeRobot environment to replay these artifacts.
  Older artifacts without `raw::` fields skip preprocessor parity; regenerate them
  with the producer to enable both comparisons.

### Fairness controls

Model parity replays inputs without re-tokenization or re-normalization. Both
sides use **fp32 + SDPA**, overriding the original's flash_attention_2 + bf16
default to avoid kernel/rounding differences. The producer records `--seed`
(default `42`); the consumer restores it immediately before flow-matching sampling.

### How to run

```bash
# Resolve a local checkpoint (GR00T-N1.7-LIBERO / libero_10)
CKPT=$(uv run python - <<'PY'
import os
from huggingface_hub import snapshot_download
print(os.path.join(snapshot_download("nvidia/GR00T-N1.7-LIBERO",
      allow_patterns=["libero_10/*"]), "libero_10"))
PY
)

# 1) Produce the original-side artifacts for all embodiments (original gr00t venv, CUDA)
CUDA_VISIBLE_DEVICES=0 /path/to/Isaac-GR00T/.venv-original/bin/python \
    tests/policies/groot/utils/dump_original_n1_7.py \
    --ckpt "$CKPT" --out-dir tests/policies/groot/artifacts --device cuda --seed 42

# 2) Run the parity test (LeRobot venv) — one parametrized case per embodiment
CUDA_VISIBLE_DEVICES=0 GROOT_PARITY_DEVICE=cuda GROOT_N1_7_LIBERO_CKPT="$CKPT" \
    uv run pytest tests/policies/groot/test_groot_vs_original.py -v -s
```

The `.npz` artifacts are local-only (gitignored, ~6–10 MB each) and are regenerated by
the producer; they are never committed. The tests **skip** (do not fail) on CI or
when the checkpoint / artifacts are absent.

#### Env knobs (all optional)

| Var                                       | Default                          | Purpose                               |
| ----------------------------------------- | -------------------------------- | ------------------------------------- |
| `GROOT_N1_7_PARITY_DIR`                   | `tests/policies/groot/artifacts` | directory of per-tag `.npz` artifacts |
| `GROOT_N1_7_LIBERO_CKPT`                  | auto (HF cache)                  | override checkpoint dir               |
| `GROOT_PARITY_DEVICE`                     | `cuda` if available              | `cpu` or `cuda`                       |
| `GROOT_PARITY_ATOL` / `GROOT_PARITY_RTOL` | `1e-3`                           | comparison tolerance                  |
